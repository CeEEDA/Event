**Critical Info for New Agent**: 
- **YOU MUST RESPOND IN GERMAN ONLY.**
- **DSE Write Protocol**: DSE controllers *do not* support Modbus Function 0x06 (Write Single Register). To write commands (Stop, Auto, Start), you MUST use Function 0x10 (Write Multiple Registers) targeting Page 16 (0x1008). You must write 2 registers simultaneously: The KEY and its Ones-Complement (e.g., Auto = Key 35701, Complement 29834). This logic is successfully implemented in . DO NOT REVERT IT to Function 0x06.
- **DSE L401 USB**: The L401 via direct USB does not expose a  port because it lacks a kernel driver. It is accessed natively via  reading the BULK IN/OUT endpoints. The  ports on the Pi belong exclusively to the SIM7600 LTE Modem.
- **LTE Networking**: Do not use  for the PPP interface. Use  and a hook in  to add the route with metric 700. This preserves the  SSH connection.
