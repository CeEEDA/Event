<analysis>**original_problem_statement:**
The user initially requested a portal for monitoring power generation assets. The project has since evolved into a comprehensive **Kirmes (Fairground) Billing System**.

**PRODUCT REQUIREMENTS (Kirmes Billing System & Kirmeskiste):**
1.  **Event & Price Management:** Admins can create events, define planning periods, and set custom prices.
2.  **Public Exhibitor Portal:** A public portal for exhibitors to register (with email verification), log in, manage their profile, view bookings, and download invoices.
3.  **Exhibitor Management:** Admins can manage exhibitors, enable Purchase on Account, and reset passwords.
4.  **Billing & Invoicing (Abrechnung):**
    *   A single button processes billing for an entire event.
    *   The system calculates costs from connection fees, surcharges, and energy consumption.
    *   It generates **ZUGFeRD-compliant** e-invoices, merging data onto a corporate letterhead PDF.
    *   Invoices are automatically emailed upon generation.
    *   Admins can search for invoices and resend them.
5.  **EMU Meter Integration:** Live energy consumption data from EMU meters can be linked to exhibitor signups and is displayed on the event detail page.
6.  **Kirmeskiste (Fairground Box) Integration:**
    *   A new device type representing a Raspberry Pi connected to 4 EMU meters with fixed IP addresses.
    *   A feature to automatically generate a setup script ( & ) to configure the Pi for data collection and syncing with the portal.
    *   A system to generate and print QR codes for each of the 4 meters.
    *   A mechanism for an admin to scan the QR code on-site to assign a specific meter to an exhibitor's signup.

**User's preferred language**: Deutsch
